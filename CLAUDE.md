# chiggi_morphe_patches

Third-party Morphe (ReVanced fork) patch bundle. Kotlin patches under `patches/src/main/kotlin/app/chiggi/<app>/`, Java extensions under `extensions/`. Build the bundle with `./gradlew :patches:build` → `patches/build/libs/patches-1.15.1.mpp`; apply with `~/tools/morphe-cli/morphe-cli.jar patch --keystore Morphe.keystore …`.

The project's law file is RULEBOOK.md — read it before any change; it overrides defaults.
